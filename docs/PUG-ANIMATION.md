# Пес Алкаша: сидячая анимация

Персонаж `content_3807e47b8d7248038d2ce244c4c0438e`, образ «Наглый хитрец».
Исходный выбранный рисунок, фронтальный вид, атлас частей и recipe сохранены
в `examples/pes-alkasha/`. Опубликована версия 1.1.0. Локальные проверочные
материалы находятся в `.data/codilya-reference/pes-alkasha/`.
Туловище, голова и две передние лапы — отдельные растровые слои. Зрачки, закрытые
веки, внутренняя часть рта и язык — векторные слои. Скрытые участки плеч и живота
дорисованы при создании атласа; это отмечено в `generated_details`.

Риг использует `motion.profile = "seated_pug"` и холст 380×560. Профиль применяется
по данным рига, не по имени или идентификатору персонажа. Обычные человеческие
риги сохраняют прежнее поведение. Мопс всегда сидит; ходьбы и вставания нет.

| Жест | Действие | Длительность при 30 fps |
| --- | --- | --- |
| `look_left` | Взгляд влево и возврат | 3 с |
| `look_right` | Взгляд вправо и возврат | 3 с |
| `open_mouth` | Открывание и закрывание рта | 3 с |
| `tongue_out` | Открывание рта, язык наружу, возврат | 3 с |
| `move_paws` | Поочерёдные движения передних лап | 3 с |
| `hide_object` | Вытянуть лапу, забрать предмет, убрать под себя, вернуть лапу | 5 с |

Моргание и лёгкое дыхание автоматические. Для прятания сцене назначается один
стандартный предмет с `hand: "left"`: это лапа слева **на экране**. Предмет сначала
лежит рядом с мопсом. После контакта движется с лапой и закрывается маской бедра.
После завершения он остаётся скрытым до конца сцены, даже если назначен другой
жест. В следующей сцене состояние реквизита задаётся заново. Голос не назначен.

Для сценария используются обычные события `kind: "gesture"` с `character_id` и
`gesture_id`. Новые жесты разрешаются по опубликованному ригу персонажа.
Краткий episode brief также поддерживает их в поле `gesture`.

Интерактивная композиция `PugMotionReview` показывает движения без звука за 27 с.
Она использует тот же `Rig`, что и обычные мультфильмы. Контрольные кадры можно
пересоздать командой:

```powershell
node renderer/pug-review.mjs examples/pes-alkasha .data/pug-review
npm --prefix renderer run test:pug
```

Обязательная библиотечная проба дополнительно проверяет общие и крупные планы
с уже существующей речевой записью. Это техническая запись для проверки рта,
она не является голосом мопса и не создаёт новых запросов ElevenLabs.

Изображения созданы встроенным imagegen для этого проекта. `three-quarter.png`
содержит выбранный пользователем макет № 3 без изменений. `front.png` — его
фронтальный вид, `parts-v1.png` — атлас для анимации. Для переноса в другую
локальную библиотеку импортируйте эти три файла в роли `three_quarter`, `front`
и `pose_reference`, затем примените `recipe.json` и выполните стандартную
подготовку и проверку персонажа. `character.json` хранит идентификатор исходной
локальной библиотеки; при новом импорте используйте выданный библиотекой ID.
