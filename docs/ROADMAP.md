# План библиотеки контента

Нумерация из согласованного плана доработок. Эти номера не совпадают с номерами разделов исходного SPEC.md.

| № | Задача | Реализация и приёмка |
| --- | --- | --- |
| 1 | Версионируемая библиотека контента | SQLite, неизменяемые ревизии/версии, сохранение старых проектов |
| 2 | Шаблоны подачи материалов | Описания, роли файлов, примеры и лимиты через MCP |
| 3 | Общий процесс импорта | Оригиналы отдельно от подготовленного пакета, draft → preparing → review → published |
| 4 | Универсальный риг персонажа | Декларативные слои, суставы, эмоции и рот |
| 5 | Подготовка персонажа из эскизов | Разметка исходных пикселей, сборка рига, явные missing_details |
| 6 | Проверочный ролик персонажа | Общий/крупные планы, жесты, мимика, речь и просмотр перед публикацией |
| 7 | Универсальные декорации | Слои, маски, позиции, перекрытия, камеры |
| 8 | Подготовка и проверка декорации | Проверка разметки и MP4 с двумя контрольными героями |
| 9 | Приём и проверка образца голоса | Формат, длительность, тишина/перегрузка, происхождение и согласия |
| 10 | Клонирование через ElevenLabs | Фоновая задача, журнал, verification, разрешённый режим/лимит |
| 11 | Привязка голоса к персонажу | Одобренная версия профиля, неизменяемая ссылка в проекте и раздельный кеш |
| 12 | Управление через MCP | Полный workflow, руководство/resources, инструменты для всех переходов |
| 13 | Сквозные проверки и документация | Новый персонаж + новая декорация + голос → MP4; версии, отмена, кеш, worker recovery |

Документация: [библиотека](CONTENT-LIBRARY.md), [персонажи](CHARACTERS.md), [декорации](ENVIRONMENTS.md), [голоса](VOICES.md), [общий MCP-процесс](CONTENT-WORKFLOW.md), [фактические результаты проверок](ACCEPTANCE.md).

Наличие реализации не означает приёмку настоящих материалов. Пользовательские эскизы, сходство настоящего клона, реальный рекламный интерфейс и Linux/WSL требуют отдельных проверок. Разметка исходников реализована; автоматическая AI-дорисовка скрытых частей не заявляется. Платные запросы требуют явного разрешения и лимита.
