# Toon: короткий запрос и звуки действий

Skill хранится в `skills/toon/SKILL.md`. Для установки скопируйте папку `toon` в `~/.codex/skills/`. В Codex вызовите `$toon` и опишите выпуск. Skill уточняет отсутствующие планы, эмоции, субтитры и эффекты с вариантами; он не задаёт их за пользователя. Сценарий и озвученный предпросмотр согласуются отдельно.

Краткий brief принимает `captions: { "enabled": false }` либо `captions: { "enabled": true, "mode": "auto" }`. Режимы: `auto`, `utterance`, `word`; последний требует проверенного alignment. Для старых клиентов отсутствие captions сохраняет прежнее поведение (включены, auto). Skill всегда передаёт согласованный выбор явно.

## Библиотека ElevenLabs Sound Effects

- `get_catalog(kind="sound_effects")` возвращает эффекты с именами, immutable ID/версиями, происхождением и quality (`ready_for_listening` или `very_quiet`).
- `start_sound_effect(name, prompt, duration_seconds, idempotency_key, allow_new_sfx, max_new_sfx_seconds)` ставит одну генерацию в persistent worker.
- Новый запрос требует `allow_new_sfx=true`, лимит не меньше длительности и не выше `TOON_MAX_SFX_SECONDS` (по умолчанию 10, диапазон 0–30; 0 запрещает новую генерацию).
- `get_job` возвращает `sound_asset` после успеха, `get_artifacts` — проверенный WAV. При повторении одинаковых параметров используются сохранённые байты, без оплаты. Название не меняет ключ кеша.
- API: `POST /v1/sound-generation`, модель `eleven_text_to_sound_v2`, без автоматического выбора другой модели. Речь продолжает использовать Eleven V4. Один запрос генерирует 0.5–30 секунд; бюджет SFX отделён от TTS.
- Эффект с пиком ниже -50 dBFS отклоняется как `SFX_TOO_QUIET`, без автоматической повторной генерации. Старые почти неслышные ресурсы остаются неизменными и помечаются `very_quiet` в каталоге.
- Исходный MP3 и журнал сохраняются; библиотека использует декодированный моно WAV 48 kHz. Сохраняются фактическая длительность, хеш, описание и модель.
- После timeout, 5xx, прерывания или неполного ответа нет автоматического платного повтора, даже с новым job key. Подтверждённый отказ 4xx допускает новый явный запрос с новым ключом после Retry-After. Успешно сохранённый ответ можно доподготовить без нового HTTP.
- `provider_billing_units` содержит заголовок `character-cost`, если провайдер его вернул; это не денежная цена. Неизвестные списания отражаются отдельно.

Официальный контракт: https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert

## Звук и действие

В полном проекте у события добавлено поле `sound`:

```json
{
    "event_id": "phone_tap",
    "at": { "kind": "utterance_start", "utterance_id": "line_1" },
    "action": { "kind": "gesture", "character_id": "buyer", "gesture_id": "tap_phone" },
    "sound": {
        "asset": { "asset_id": "sfx_REPLACE_FROM_CATALOG", "version": "1.0.0" },
        "gain_db": -12,
        "offset_ms": 0
    }
}
```

Для краткого brief добавьте `gesture: "tap_phone"` и такой же `sound` в реплику. Звук у реплики требует явного жеста. Можно использовать любой зарегистрированный audio asset, включая импортированный через `register_asset`.

`tap_phone` показывает телефон и нажатие с контактом на кадре 18 после начала жеста (600 мс при закреплённых 30 fps). Звук начинается на этом же кадре. У остальных действий звук начинается на кадре события. `offset_ms` добавляет задержку 0–3000 мс с округлением к кадру. Автоматического добавления звука к жестам нет.

Громкость задаётся `gain_db` от -60 до 0 (по умолчанию -12). Звук должен полностью помещаться в сцену: при необходимости увеличьте `tail_ms` или сдвиньте событие. Речь и эффект не обрезаются. Предпросмотр и MP4 используют один микшер; финальная нормализация громкости применяется при экспорте. Таймлайн содержит фактические sample positions и хеши; WAV включается в финальный ZIP. Запись эффекта может содержать начальную тишину: кадр привязки определяет начало аудиофайла, акустическую атаку нужно прослушать.

## Проверки

`./scripts/acceptance.ps1 -Sounds` проверяет mock HTTP, бюджет, кеш, идемпотентность, неизвестный исход, выключенные субтитры, PCM-синхронизацию, финальный MP4 и ZIP. Платных запросов в этой проверке нет.

Только после разрешения и с запущенным worker: `dotnet tests/Toon.Acceptance/bin/Debug/net10.0/Toon.Acceptance.dll --live-sfx 3` генерирует до трёх заданных эффектов по 2 секунды (tap, notification, error) в `TOON_DATA_ROOT`. Постоянные ключи задания защищают от повторной генерации при повторе команды. Отчёт: `live-sound-acceptance.json` в data root. Доступность MCP-инструментов после обновления сборки требует переподключения клиента.

Проверено 27 октября 2026: сборки Debug/Release, TypeScript, skill validator, быстрая регрессия и SFX acceptance с реальным финальным MP4. В живой библиотеке Алкаша созданы notification, error и отчётливый tap (по 2 секунды). Пять обращений в согласованном лимите: один отказ HTTP 401 до изменения разрешений ключа, четыре ответа с аудио, из них первый tap почти неслышен. Провайдер вернул character-cost=20 для каждого успешного ответа (сумма 80 provider units, не денежная оценка). Проверка акустического качества человеком остаётся необходимой.
