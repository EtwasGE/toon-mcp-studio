# Задание для Codex

Создай работоспособный Toon MCP по SPEC.md из этого пакета. Это спецификация разработки; готовой реализации в пакете нет.

Сначала прочитай SPEC.md, ANIMATION-AND-QA.md, contracts/project.schema.json, contracts/audio-alignment.schema.json, contracts/README-contracts.md и examples/novostroykin.project.json. Если в рабочем репозитории есть AGENTS.md и существующий код, изучи их и сохрани несвязанные изменения.

Реализуй локальную систему на .NET 10: stdio MCP, отдельный persistent worker, SQLite и файловое хранилище. Рендерер — TypeScript/React/Remotion, управляемый данными. Не создавай новый React-проект на каждый ролик. Используй оригинальные персонажи и ассеты.

Начни с автономного вертикального среза JSON → озвученные сцены → проверенный MP4. Затем добавь устойчивое хранение, MCP и ElevenLabs. Работай по этапам SPEC.md; после каждого должен оставаться запускаемый результат.

Сделай два постоянных персонажа, две локации, общий и крупные планы, жесты, простую анимацию рта, субтитры и телефон с точным изображением интерфейса. Получай финальные длительности из аудио. Не обрезай речь, не выдумывай word timing и не называй движение рта по громкости точной артикуляцией.

Сохраняй проекты с ревизиями, кешируй аудио, делай start_render идемпотентным. Worker должен продолжать работу после закрытия MCP. Реализуй отмену процессов, проверку результатов и корректные ошибки. Не выдавай mock или partial файл за готовое видео.

Проверяй доступные локальные runtime и актуальную официальную документацию. Зафиксируй совместимые версии пакетов. Подключение Codex выполни по справке установленной версии и покажи рабочую команду. Секреты бери из окружения; не помещай их в проект, логи или Git.

Если нет API-ключей или реальных скриншотов, продолжай все независимые задачи и offline проверки. Для тестов допустимы явно обозначенные fixtures. Живую TTS-интеграцию и рекламный пример с настоящим интерфейсом отмечай pending, пока нужных данных нет. Не запускай оплачиваемые запросы без разрешённого режима и лимита.

До окончания работы проведи критерии A01–A21 в применимой части, визуально проверь контрольные кадры и прослушай реальный речевой ролик. В финале укажи команды запуска, пути к MP4 и проекту, результаты проверок и конкретные непроверенные пункты. Не останавливайся после одного каркаса классов или успешного tools/list.
