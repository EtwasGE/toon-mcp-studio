# Пакет технического задания Toon MCP

Этот архив подготовлен для передачи Codex. Он содержит ТЗ, контракт данных и пример проекта. Сервер, рендерер и видеоролик предстоит реализовать по заданию.

## Как использовать

1. Распаковать архив в отдельную папку проекта или в `docs/toon-mcp-spec` существующего репозитория.
2. Передать Codex текст из `CODEX-START.md` и путь к этой папке.
3. Попросить начать с первого сквозного этапа в `SPEC.md`.

## Состав

| Файл | Назначение |
| --- | --- |
| SPEC.md | Полное ТЗ, архитектура, API, этапы и критерии приёмки |
| CODEX-START.md | Готовое стартовое задание агенту |
| ANIMATION-AND-QA.md | Требования к персонажам, анимации, речи, монтажу и проверке |
| contracts/project.schema.json | Структурная JSON Schema DraftProject |
| contracts/audio-alignment.schema.json | Схема разметки слов записанной реплики |
| contracts/README-contracts.md | Семантика данных и проверки сверх JSON Schema |
| examples/novostroykin.project.json | Сценарный пример для Новостройкина |
| examples/recorded-line.alignment.json | Иллюстративная разметка без аудиозаписи; не использовать как готовый alignment |
| validate_contracts.py | Повторяемая структурная проверка схем и примеров |
| VALIDATION.md | Выполненные проверки пакета и их границы |

Числовые лимиты и интерфейсы SPEC.md обязательны. JSON Schema определяет синтаксис DraftProject, а README-contracts — его семантику. ANIMATION-AND-QA конкретизирует художественные и технические критерии. При обнаружении противоречия сначала исправить контракт и пример согласованно, затем писать код.

Пример проходит структурную проверку схемой. Ссылки на персонажей, фоны, голоса и скриншоты являются проектными именами: соответствующие реальные материалы создаются или регистрируются при разработке. Одной структурной валидности недостаточно для рендера.

Для повторной проверки контрактов установить Python-пакет `jsonschema` в отдельное виртуальное окружение и выполнить `python validate_contracts.py` из папки пакета. Эта проверка не запускает рендер и не обращается к платным API.

В архив не включены чужие видео, материалы платных пакетов codil.ya, ключи API или скриншоты интерфейса бота. Источники исследования указаны в SPEC.md. Все исходные тексты примера предназначены для собственного проекта пользователя.
