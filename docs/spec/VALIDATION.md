# Проверка комплекта технического задания

Дата: 26 октября 2026 года.

## Выполнено

- Схемы DraftProject и WordAlignment проверены валидатором JSON Schema Draft 2020-12.
- Оба JSON-примера проходят структурную проверку.
- Вариант проекта с готовой аудиозаписью и три режима captions проходят структурную проверку.
- Восемь намеренно некорректных примеров отклоняются: неподдерживаемый fps, готовые кадры в draft, поле секретного ключа, речь в hold, crop скриншота, неизвестный caption mode, production alignment без происхождения, ложная отметка проверки у иллюстративного alignment.
- Проверены индексы, последовательность времён и диапазоны отображаемых слов у иллюстративной разметки.
- Документы сопоставлены по версии схемы, именам ошибок, стадиям worker, формату кадров, голосовым alias, режимам captions и допустимым операциям MVP.

Для воспроизведения проверки использовать `validate_contracts.py` с установленным пакетом `jsonschema`.

## Границы результата

Это проверка спецификации, а не работающего приложения. MCP-сервер, worker, рендерер и художественные ассеты ещё предстоит реализовать. Рендер, подключения клиентов, живая озвучка и критерии A01–A21 сейчас не выполнялись.

Пример Новостройкина требует реальных персонажей/фонов и зарегистрированного скриншота; voice aliases не привязаны к облачным голосам. Файл recorded-line.alignment.json содержит вымышленные демонстрационные времена и помечен example_only; соответствующего аудио в комплекте нет. Структурная валидность этих файлов не означает готовность к производственному рендеру.
