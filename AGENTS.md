# Оформление кода

Ориентир для C# — стиль JK-Telegram-Bots. Применяйте эти правила и к новому коду, и к изменяемым участкам:

- Четыре пробела, без табуляции. Фигурные скобки блоков на отдельной строке (Allman).
- Один оператор на строку. Между методами оставляйте пустую строку.
- Длинные списки аргументов и LINQ-цепочки разбивайте на строки; ориентир ширины — 120 символов.
- У `foreach`, `await foreach`, `for`, `while` и `do ... while` всегда должны быть фигурные скобки, даже при одном операторе.
- У однострочной ветки `if` фигурные скобки обязательны, кроме непосредственного `return` или `throw`. Например, `if (invalid) return;` допустимо; вызов метода, присваивание, `break` и `continue` требуют блока.
- То же правило действует для `else`; конструкцию `else if` сохраняйте цепочкой. Уже существующие блоки вокруг `return` и `throw` удалять не обязательно.
- Между соседними самостоятельными `if` оставляйте пустую строку, включая guard clauses. Внутри цепочки `else if` дополнительная пустая строка не требуется.
- Короткие auto-properties оставляйте в одну строку: `public string Name { get; }`.
- В XML-файлах проектов — два пробела. В TypeScript/React и JSON — четыре пробела; настройки находятся в `.prettierrc.json`.
- Правила блоков циклов, веток `if` и пустых строк между `if` также применяются к TypeScript/JavaScript.
- При изменении оформления сохраняйте поведение, строковые значения, комментарии и текущие пользовательские изменения.

Пример:

~~~csharp
if (value is null)
    return;

if (shouldUpdate)
{
    Update(value);
}

foreach (var item in items)
{
    Process(item);
}
~~~

`.editorconfig` задаёт оформление редактора. CSharpier сохраняет блоки, но не заменяет проверку перечисленных правил для `if` и циклов.
