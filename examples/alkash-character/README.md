# Алкаш: исходники персонажа

`approved-sheet.png` — согласованный эскиз. `animation-layers.png` — прозрачные детали, подготовленные встроенным imagegen; запрос сохранён в `imagegen-prompt.txt`.

`character.recipe.json` — рецепт опубликованного рига 1.2.0: цельная майка, перекрытия шеи и плеч, состояния рта, моргание и поза с телефоном. Это фронтальная 2D-постановка, не полный набор ракурсов.

Для новой локальной библиотеки создайте character item, импортируйте `animation-layers.png` с ролью `front`, установите рецепт через `set_character_recipe`, затем выполните `prepare_library_item`. Перед публикацией нужен `start_character_test` с собственной разрешённой речевой записью и просмотр результата. Порядок описан в `docs/CHARACTERS.md`.

Идентификаторы локальной библиотеки, голосовые профили, речь и готовые MP4 сюда не включены. Эти исходники сами по себе не выполняют платных запросов.
