# Оригинальная тестовая мастерская

`wide.png` создаётся нашим `scripts/create-environment-fixture.py` (Python + Pillow). Это явно обозначенный synthetic fixture, а не пользовательский эскиз и не рекламный интерфейс.

Разметка находится в `templates/library/environment-recipe.json`: фон, растение между глубинами двух героев, стол перед ними. Контуры растения вырезаются отдельными масками; исходное изображение сохраняется. Координаты шаблона подходят только этому изображению.
