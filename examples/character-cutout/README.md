# Синтетический лист для проверки ригов

`sheet.png` — оригинальный рисунок, созданный `scripts/create-character-fixture.py` из простых геометрических элементов. Это техническая fixture; не пользовательский эскиз, не портрет реального человека и не результат автоматической сегментации.

Лист 640×512 состоит из ячеек 128×128: туловище, голова, две руки, глаза открытые/закрытые, четыре состояния рта, шесть выражений бровей, телефон и ноги. [Пример разметки](../../templates/library/character-recipe.json) собирает их на холсте персонажа 380×560.

В сквозном тесте тот же лист импортируется и в роль `three_quarter` исключительно для проверки инфраструктуры обязательных материалов. Он не подтверждает поддержку нового ракурса. Настоящий рисунок в три четверти служит справочным материалом художнику; текущая анимация остаётся фронтальной 2D.

Озвучка теста берётся из локальной речевой fixture `examples/offline-dialogue/problem.wav`, которая не входит в публичный Git. Для получения записи служит `scripts/prepare-fixtures.ps1`; ограничения её распространения описаны в основном README.
