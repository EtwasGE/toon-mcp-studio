# Тёплая редакционная 2D-графика

Версия 1.0.0. Два оригинальных героя: покупатель в терракотовой рубашке с круглым лицом и советник в бирюзовом кардигане, с очками и бородой. Не менять их облик от сцены к сцене. SVG rig встроен в renderer/src/Rig.tsx; пользовательский код не исполняется.

Короткая история: конкретная проблема → ответ собеседника → наглядный предмет → реакция → ясное действие. Реплики по одному предложению. В каждом диалоге есть кадрозависимые микродвижения головы, независимое моргание и реакция; жест добавляется по смыслу. Общий план показывает отношения героев, крупный — говорящего или реакцию. Оба close_up доступны только для видимого cast. Крупности переключаются за 180–250 мс; не накладывать переходы.

idle 30 кадров; blink 8; nod 32; shake_head 36; raise_hand и shrug 54; show_phone 120. Жест возвращается к исходной позе; новый жест прерывает текущий. Телефон в руке — символ реквизита, не экран продукта. Для чтения интерфейса перейти на screen и вставить зарегистрированный PNG/JPEG с exact + contain. Телефон и изображение не отражаются, не обрезаются. Не использовать учебный экран как настоящий интерфейс.

Заголовок наверху, субтитры под героями, CTA в центре отдельной hold-сцены. Safe area: x=80..900, y=180..1580. Шрифт Noto Sans Bold 52px, не больше двух строк. Если фраза не помещается, сократить сценарий или добавить проверенную разметку; не придумывать интервалы. Word anchors допустимы только с alignment.

Речь идёт последовательно; сначала готовое аудио, затем таймлайн. Mouth mode approximate/amplitude: четыре состояния, сглаживание и гистерезис; это не фонемная артикуляция. Не обещать синхронное произношение по буквам. Музыка только из разрешённого импорта и с ducking.
